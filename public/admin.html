Announcements from email (0 live)

Emails sent or forwarded to concierge@tucsonymca.org become announcements the concierge uses until they expire. Attached PDF and image flyers are read too, and shown to staff with the answer. Emails from @tucsonymca.org go live right away; others wait for approval here.

Gmail connection setup
  1. Sign in to Gmail as concierge@tucsonymca.org (use a private/incognito window so you don't mix it up with your own account).
  2. In that same window, go to script.google.com → New project.
  3. Delete what's there, click Copy script below, and paste it in. Click the 💾 save icon.
  4. In the function dropdown at the top pick setup, then click Run. Approve the permissions Google asks for (choose the concierge account; if it says "Google hasn't verified this app", click Advanced → Go to project).
  5. Done — it now checks the mailbox every 5 minutes. New emails show up in the list above.

The script contains a private key that lets it send emails to the concierge — keep it in that Google account only.
